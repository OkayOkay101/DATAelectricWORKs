# คู่มือการเริ่มต้นใช้งานอย่างรวดเร็ว (Quickstart Guide)

ยินดีต้อนรับสู่โปรแกรม **Load Profile & TOU Simulator** คู่มือฉบับนี้จะแนะนำขั้นตอนการติดตั้งและเปิดใช้งานโปรแกรมเบื้องต้น

## 1. สิ่งที่ต้องเตรียม (Prerequisites)

โปรแกรมนี้ต้องการไลบรารี Python ต่อไปนี้เพื่อให้ทำงานได้อย่างสมบูรณ์ (อ้างอิงจาก `app.py` และ `generate_mock_data.py`):
- `pandas`
- `numpy`
- `plotly`
- `streamlit`
- `openpyxl` (สำหรับอ่าน/เขียนไฟล์ Excel .xlsx)
- `xlrd` (สำหรับอ่านไฟล์ Excel .xls)
- `xlwt` (สำหรับสร้าง/เขียนไฟล์ Excel .xls)

## 2. การตั้งค่าสภาพแวดล้อมเสมือน (Virtual Environment)

เพื่อให้ไลบรารีของโปรแกรมไม่ปะปนกับระบบหลัก แนะนำให้สร้างและใช้งาน Virtual Environment ดังนี้:

### การสร้าง Virtual Environment
เปิด Terminal หรือ Command Prompt แล้วรันคำสั่ง:
```bash
python -m venv venv
```

### การเปิดใช้งาน (Activate) Virtual Environment
- **Windows:**
  ```cmd
  venv\Scripts\activate
  ```
- **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

หลังจาก Activate แล้ว คุณสามารถติดตั้งไลบรารีด้วย `pip install`

## 3. การเปิดใช้งานโปรแกรม (Starting the App)

โปรแกรมนี้เป็นเว็บแอปพลิเคชันที่สร้างด้วย Streamlit คุณสามารถเริ่มต้นโปรแกรมได้โดยใช้คำสั่ง:
```bash
streamlit run app.py
```
เบราว์เซอร์จะเปิดขึ้นมาพร้อมกับหน้าจอของโปรแกรมโดยอัตโนมัติ

## 4. ตัวเลือกเสริม: การเปิดใช้งานผ่าน Launcher

คุณยังสามารถเปิดใช้งานโปรแกรมได้อีกวิธีผ่านไฟล์ Launcher `run_main.py` ซึ่งจะสั่งรัน Streamlit ตามที่ตั้งค่าไว้ในไฟล์:
```bash
python run_main.py
```

## 5. การสร้างข้อมูลทดสอบ (Mock Data)

หากคุณไม่มีข้อมูลที่แท้จริงสำหรับการทดสอบระบบ คุณสามารถสร้างข้อมูลตัวอย่าง (Mock Data) ในรูปแบบไฟล์ `.csv`, `.xlsx`, `.xls`, และ `.txt` ได้โดยใช้คำสั่ง:
```bash
python generate_mock_data.py
```
ไฟล์ข้อมูลตัวอย่างจะถูกสร้างและจัดเก็บไว้ในโฟลเดอร์ `mock_data/` โดยอัตโนมัติ เพื่อให้คุณพร้อมนำไปอัปโหลดเข้าโปรแกรม
