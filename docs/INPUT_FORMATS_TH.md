# คู่มือรูปแบบข้อมูลนำเข้า (Thai Input-Format Guide)

คู่มือนี้อธิบายรูปแบบข้อมูลนำเข้าที่รองรับโดยระบบ (อ้างอิงจาก `data_handler.py` และ `generate_mock_data.py`)

## 1. รูปแบบไฟล์ที่รองรับ
- ไฟล์ที่รองรับ: `.csv`, `.txt`, `.xls`, `.xlsx`

## 2. โครงสร้างคอลัมน์และหัวตาราง
หัวตารางต้องอยู่ใน **50 บรรทัดแรก** ของไฟล์ ระบบค้นหาคอลัมน์โดยใช้คำสำคัญต่อไปนี้ (ไม่สนใจพิมพ์เล็ก-พิมพ์ใหญ่):

*   **วัน/เวลา (Date/Clock):** รองรับคอลัมน์แยก (เช่น Date และ Clock) หรือคอลัมน์รวม (เช่น Clock, Time, Datatime, CH1, เวลา, วันที่)
*   **พลังงานนำเข้า (kW_Import):** ค้นหาคอลัมน์ที่มีคำว่า kW, Import, Active Power, Demand, พลังงาน, กำลังไฟฟ้า หรือ CH4
    *   *ข้อจำกัด:* หากมีหลายคอลัมน์ที่เข้าข่าย ระบบจะรวมคอลัมน์ที่มีผลรวมข้อมูลสูงสุด เพื่อป้องกันกราฟแสดงค่าเป็น 0
*   **แรงดันไฟฟ้า (Voltage):** ค้นหาคอลัมน์ที่มีคำว่า Voltage, Volt, V, แรงดัน หรือ CH3 (ค่าปริยายหากไม่มีคือ 220)

*   *ข้อจำกัดการตั้งชื่อคอลัมน์:* หากมีชื่อคอลัมน์ซ้ำกัน คอลัมน์ที่ซ้ำจะถูกเปลี่ยนชื่อโดยอัตโนมัติ (เช่นเติม `_1`, `_2`)

## 3. ตัวคั่น (Delimiters สำหรับไฟล์ TXT/CSV)
ระบบตรวจสอบและรองรับตัวคั่น (Delimiters) ดังนี้:
- จุลภาค `,` (Comma)
- แท็บ `\t` (Tab)
- อัฒภาค `;` (Semicolon)
- ช่องว่าง (Space)

## 4. การจัดการวันที่และเวลา (Date/Time Parsing)
- รองรับรูปแบบวันเวลาที่ขึ้นต้นด้วยวัน เช่น `dd/mm/yyyy HH:MM` (จาก `pd.to_datetime(dayfirst=True)`)
- หากพบค่าที่ไม่ถูกต้อง (เช่น 'total', 'p', 'op', 'h', 'kwh', 'nan', 'dnv/err') ในคอลัมน์เวลา ข้อมูลบรรทัดนั้นจะถูกข้าม

## 5. การจัดการหน่วยตัวเลข (Numeric Units)
- ระบบจะกรองข้อความและสัญลักษณ์อื่น ๆ ออก เหลือไว้เพียงตัวเลขและจุดทศนิยมโดยใช้ Regular Expression (`[^\d.]`)
- **คำเตือน (Limitation):** การใช้ Regex ลักษณะนี้จะตัดเครื่องหมายลบ (`-`) ออกไปด้วย ทำให้ตัวเลขทั้งหมดกลายเป็นค่าบวก
- ค่าพลังงานนำเข้าที่เกิน 2,000,000 จะถูกตัดออกเป็น Outlier

## 6. ตัวอย่างข้อมูล (Sample Input)
ตัวอย่างโครงสร้างข้อมูลจากชุดทดสอบ (Mock Data):

| Clock | kW_Import | Voltage |
| :--- | :--- | :--- |
| 01/01/2026 00:00 | 50.00 | 220.00 |
| 01/01/2026 08:00 | 200.00 | 220.00 |
| 01/01/2026 12:00 | 450.00 | 245.00 |

## การตรวจสอบแหล่งที่มาและการทดสอบ
- **Source Review:** กฎเกณฑ์ข้างต้นได้มาจากการตรวจสอบโค้ดใน `data_handler.py` และ `generate_mock_data.py` ในเวอร์ชันปัจจุบัน
- **Runtime Verification:** การทดสอบความถูกต้องกับระบบในขณะทำงานจริง (Runtime) แยกส่วนจากการตรวจสอบและบันทึกเอกสารนี้
