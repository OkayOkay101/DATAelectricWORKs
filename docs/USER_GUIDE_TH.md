# คู่มือผู้ใช้งาน: Load Profile & TOU Simulator

> 🇬🇧 English version: [USER_GUIDE_EN.md](USER_GUIDE_EN.md)

คู่มือนี้สำหรับผู้ใช้ใหม่ อธิบายว่าโปรแกรมทำอะไรได้บ้าง ต้องเตรียมอะไร ใช้งานทีละขั้นตอนอย่างไร และแต่ละหน้าจอแสดงผลอะไร

> ถ้ายังไม่ได้ติดตั้งโปรแกรม ให้เริ่มที่ [คู่มือเริ่มต้นใช้งานอย่างรวดเร็ว](GETTING_STARTED_TH.md) ก่อน
> ถ้าไฟล์อัปโหลดไม่ผ่าน ดู [รูปแบบข้อมูลนำเข้า](INPUT_FORMATS_TH.md) และ [แก้ปัญหาการใช้งาน](TROUBLESHOOTING_TH.md)

---

## 1. โปรแกรมนี้ทำอะไรได้บ้าง

โปรแกรมนี้รับไฟล์ **Load Profile** (ข้อมูลการใช้ไฟฟ้าที่บันทึกทุก 15 นาที จากการไฟฟ้าหรือเครื่องบันทึกข้อมูล หรือ Data Logger) แล้วช่วยคุณ:

- **ดูภาพรวมการใช้พลังงาน** เช่น พลังงานรวม (kWh), ความต้องการไฟฟ้าสูงสุด (kW), และค่าไฟฟ้าโดยประมาณ
- **ดูข้อมูลรายวัน** ว่าวันใดใช้ไฟมาก และช่วงเวลาไหนของวันมีโหลดสูง
- **ตรวจจับจุดผิดปกติ** เช่น โหลดสูงกว่าเกณฑ์ปกติ หรือไฟตกผิดปกติ
- **จำลองการเลื่อนเวลา** เพื่อดูว่าถ้าเปลี่ยนเวลาการใช้ไฟ (เช่น เลื่อนงานไปนอกช่วง On-Peak) ค่าไฟจะเปลี่ยนไปเท่าไร
- **คำนวณค่าไฟ** ได้ทั้งแบบ **TOU** (Time of Use: แยกเรทตามช่วงเวลา) และแบบ **อัตราเดียว** (Single Rate)
- **ดาวน์โหลดผลลัพธ์** เป็นไฟล์ CSV หรือ Excel เพื่อนำไปใช้ต่อ

โปรแกรมทำงานบนเว็บเบราว์เซอร์ในเครื่องของคุณ ข้อมูลไม่ได้ถูกส่งไปที่อื่น

---

## 2. สิ่งที่ต้องเตรียม

1. **ไฟล์ข้อมูลการใช้ไฟฟ้า** ที่มีคอลัมน์เวลา และคอลัมน์ค่ากำลังไฟฟ้า (kW) รองรับ `.csv`, `.txt`, `.xlsx`, `.xls`
   - ถ้ายังไม่มีไฟล์จริง ลองดาวน์โหลดไฟล์ตัวอย่างจากปุ่ม "📥 ดาวน์โหลดไฟล์ตัวอย่างแม่แบบ (.csv)" ที่หน้าแรกของโปรแกรม
2. **ติดตั้งโปรแกรม** ตามขั้นตอนใน [คู่มือเริ่มต้นใช้งาน](GETTING_STARTED_TH.md)
3. **เปิดโปรแกรม** ด้วยคำสั่ง `streamlit run app.py` แล้วเบราว์เซอร์จะเปิดหน้าโปรแกรมให้

ข้อจำกัดการอัปโหลด:

| รายการ | ค่าสูงสุด |
| :--- | :--- |
| จำนวนไฟล์ต่อครั้ง | 20 ไฟล์ |
| ขนาดต่อไฟล์ | 50 MB |
| ขนาดรวมทุกไฟล์ | 200 MB |

## 3. ภาพรวมหน้าจอ

หน้าจอแบ่งเป็น 2 ส่วนหลัก

### แถบด้านซ้าย (Sidebar) สำหรับตั้งค่า

| ส่วน | ทำอะไร |
| :--- | :--- |
| **1. อัปโหลดข้อมูล** | ลากไฟล์มาวาง หรือกดเลือกไฟล์ที่ต้องการวิเคราะห์ |
| **2. ตั้งค่าระบบคิดเงิน** | เลือกประเภทอัตราค่าไฟ กรอกเรทราคา เวลา On-Peak และรายการวันหยุด |
| **3. ตั้งค่าการแสดงผล** | เลือกรูปแบบกราฟ (แท่งหรือเส้น) และปรับความไวการตรวจจับจุดผิดปกติ |

### พื้นที่หลัก (Main Area)

- **ก่อนอัปโหลดไฟล์:** หน้าต้อนรับจะแสดงขั้นตอน 1 ถึง 3 และมีปุ่มดาวน์โหลดไฟล์ตัวอย่าง
- **หลังอัปโหลดไฟล์:** จะแสดงช่วงวันเวลาของข้อมูล จำนวนแถว ตัวกรองรอบการทำงาน และแท็บ 4 แท็บ

---

## 4. ขั้นตอนการใช้งานแบบทีละขั้น

### ขั้นที่ 1: อัปโหลดไฟล์

1. ในแถบด้านซ้าย ส่วน **1. อัปโหลดข้อมูล** ลากไฟล์มาวาง หรือกดเพื่อเลือกไฟล์
2. ถ้าอัปโหลดหลายไฟล์ โปรแกรมจะรวมข้อมูลให้โดยอัตโนมัติ
3. ถ้ามีไฟล์ที่อ่านไม่ได้ โปรแกรมจะแสดงข้อความ "⚠️ ข้ามไฟล์..." พร้อมเหตุผล และยังวิเคราะห์ไฟล์ที่อ่านได้ต่อ
4. เมื่ออัปโหลดสำเร็จ จะขึ้นข้อความ "✅ วิเคราะห์ข้อมูลสำเร็จ" และแสดงช่วงวันเวลาของข้อมูลใต้หัวข้อ

### ขั้นที่ 2: ตั้งค่าการคิดค่าไฟ

1. เลือก **ประเภทอัตราค่าไฟ**
   - **TOU (Time of Use):** ค่าไฟต่างกันตามช่วงเวลา ต้องกรอกเรท On-Peak และเรท Off-Peak / Holiday
   - **อัตราเดียว (Single Rate):** ค่าไฟเท่ากันทุกช่วงเวลา กรอกเรทเดียว
2. ตรวจเรทราคาในหัวข้อ "ตั้งค่าเรทราคา (บาท/หน่วย)" ให้ตรงกับใบเรียกเก็บเงินของคุณ ค่าเริ่มต้นเป็นตัวอย่างเท่านั้น
3. ตั้งเวลา **On-Peak** ในหัวข้อ "ตั้งค่าเวลา On-Peak" ค่าเริ่มต้นคือ 09:00 ถึง 22:00
   - ถ้าตั้งเวลาเริ่มและสิ้นสุดให้เท่ากัน ระบบจะไม่คิดค่าไฟช่วง On-Peak เลย
   - ถ้าเวลาสิ้นสุดน้อยกว่าเวลาเริ่ม ระบบถือว่าช่วง On-Peak ข้ามเที่ยงคืน
4. ตรวจรายการ **วันหยุดนักขัตฤกษ์** ในหัวข้อ "ตั้งค่าวันหยุดนักขัตฤกษ์" พิมพ์วันที่แบบ `YYYY-MM-DD` คั่นด้วยลูกน้ำ วันหยุดในรายการจะถูกคิดเป็นเรท Off-Peak / Holiday ทั้งวัน
   - วันหยุดที่พิมพ์ผิดรูปแบบหรือไม่มีจริงจะถูกละเว้น
   - ค่าเริ่มต้นเป็นรายการวันหยุดของปีปัจจุบัน ถ้าต้องการปีอื่นให้แก้ไขเอง

### ขั้นที่ 3: เลือกตัวกรองรอบการทำงาน (ถ้ามี)

ใต้หัวข้อข้อมูลช่วงวันเวลา จะมีตัวกรอง **"กรองช่วงเวลา"** ถ้าข้อมูลมีหลายรอบการทำงาน (snapshot) ให้เลือกรอบที่ต้องการดู ทุกแท็บจะคำนวณเฉพาะช่วงนั้น

### ขั้นที่ 4: ดูผลลัพธ์ในแต่ละแท็บ

ดูรายละเอียดในหัวข้อ 5 ด้านล่าง

## 5. คำอธิบายแต่ละแท็บ

### แท็บ 1: ภาพรวมพลังงาน (Overview)

- **การ์ดตัวเลข 4 ใบ**
  - ⚡ **พลังงานไฟฟ้ารวม (kWh):** ผลรวมพลังงานในช่วงที่เลือก
  - 🔥 **ความต้องการไฟฟ้าสูงสุด (Peak, kW):** ค่ากำลังไฟฟ้าสูงสุดที่เกิดขึ้น
  - 💰 **ค่าไฟฟ้าประเมินรวม (บาท):** คำนวณจากเรทที่ตั้งไว้ในแถบด้านซ้าย
  - 📊 **กำลังไฟฟ้าเฉลี่ย (kW)**
- **กราฟความต้องการรวมและจุดผิดปกติ (kW):** แสดงกราฟโหลดตลอดช่วงเวลา พร้อมจุดสามเหลี่ยมที่ระบุโหลดผิดปกติ
  - ▲ สีแดง = โหลดสูงกว่าเกณฑ์
  - ▼ สีน้ำเงิน = ไฟตก (โหลดต่ำกว่าเกณฑ์)
- **กราฟ kW และ kWh ราย 15 นาที** และ **กราฟพลังงานรวมรายวัน (kWh)** พร้อมตารางรวมรายวันที่ดาวน์โหลดได้

สีของช่วงเวลาในกราฟ

| สี | ความหมาย |
| :--- | :--- |
| 🟧 ส้ม | On-Peak (ช่วงเวลาที่ตั้งไว้ วันทำการ) |
| 🟩 เขียว | Off-Peak (กลางคืน หรือเสาร์-อาทิตย์) |
| 🟨 เหลือง | Holiday (วันหยุดนักขัตฤกษ์ในรายการ) |

### แท็บ 2: เจาะลึกรายวัน (Daily Insights)

- เลือกวันที่ต้องการดูจากช่อง **"📅 เลือกวันที่ต้องการเจาะลึก"**
- แสดงการ์ดสรุปของวันนั้น และกราฟ 15 นาทีของวันนั้นพร้อมจุดผิดปกติ
- มีตารางข้อมูลราย 15 นาที และปุ่มดาวน์โหลดข้อมูลของวันนั้น
- ถ้าไม่มีวันที่ให้เลือก ระบบจะแสดงข้อความว่าไม่พบข้อมูลวันที่

### แท็บ 3: กราฟจำลองเวลา (Shift Graph)

ใช้ทดลองว่า **ถ้าเลื่อนเวลาการใช้ไฟ จะเกิดอะไรขึ้น**

1. กรอก **จำนวนนาทีที่ต้องการเลื่อน** โดยปรับทีละ 15 นาที
   - ค่าบวก (+) = เลื่อนไปข้างหน้า
   - ค่าลบ (-) = เลื่อนถอยหลัง
   - ค่า 0 คือเวลาเดิม
2. เลือกวันที่ข้อมูลที่ต้องการเปรียบเทียบ
3. ระบบจะแสดง
   - กราฟเส้นเปรียบเทียบ เส้นทึบสีน้ำเงินคือข้อมูลเดิม เส้นประสีแดงคือข้อมูลหลังเลื่อนเวลา
   - ผลการจำลองค่าไฟ บอกว่าประหยัดขึ้น เพิ่มขึ้น หรือคงเดิม พร้อมจำนวนบาทและเปอร์เซ็นต์
4. กดดาวน์โหลดผลการจำลองได้

> ตัวอย่าง: ถ้าเลื่อนงานหนักจาก 10:00 ไปหลัง 22:00 ซึ่งเป็น Off-Peak ค่าไฟที่ประเมินได้จะลดลง

### แท็บ 4: วิเคราะห์ค่าไฟ & จำลอง (Cost Simulator)

ขอบเขตการสรุปผล เลือกได้ 4 แบบ

| แบบ | ความหมาย |
| :--- | :--- |
| ภาพรวมทั้งหมด (Total) | สรุปทั้งไฟล์ |
| รายเดือน (Monthly) | สรุปแยกเดือน |
| รายวัน (Daily) | สรุปแยกวัน เลือกวันที่ได้ |
| กำหนดช่วงเวลา (Custom) | เลือกวันเริ่มและวันสิ้นสุดเอง |

ผลที่แสดง ได้แก่ พลังงานรวมแยกตามช่วงเวลา (On-Peak, Off-Peak, Holiday) ค่าไฟแยกตามช่วงเวลา และค่าไฟรวม พร้อมตารางและปุ่มดาวน์โหลดไฟล์ CSV

ส่วนจำลองค่าไฟในแท็บนี้ใช้หลักการเดียวกับแท็บ 3 คือกรอกเวลาที่ต้องการเลื่อน (นาที) แล้วดูผลต่างของค่าไฟ

## 6. คำศัพท์ที่ควรรู้

| คำศัพท์ | ความหมาย |
| :--- | :--- |
| **Load Profile** | ข้อมูลกำลังไฟฟ้าที่บันทึกต่อเนื่องตามเวลา มักเป็นทุก 15 นาที |
| **kW (กิโลวัตต์)** | กำลังไฟฟ้า ณ ขณะหนึ่ง |
| **kWh (กิโลวัตต์-ชั่วโมง)** | พลังงานไฟฟ้าที่ใช้ไปในช่วงเวลาหนึ่ง โปรแกรมคำนวณเป็น kW ÷ 4 สำหรับแต่ละช่วง 15 นาที (เพราะ 15 นาที = 0.25 ชั่วโมง) |
| **TOU (Time of Use)** | อัตราค่าไฟที่แยกเรทตามช่วงเวลา |
| **On-Peak** | ช่วงเวลาที่มีเรทแพงที่สุดตามที่ตั้งไว้ โดยทั่วไปคือช่วงกลางวันวันทำการ |
| **Off-Peak** | ช่วงเวลาที่มีเรทถูกกว่า ได้แก่ นอกช่วง On-Peak และวันเสาร์-อาทิตย์ |
| **Holiday** | วันหยุดนักขัตฤกษ์ที่กำหนดไว้ในรายการ คิดเรท Off-Peak / Holiday ทั้งวัน |
| **Anomaly (จุดผิดปกติ)** | ค่าที่สูงหรือต่ำกว่าช่วงปกติมากเกินไป โปรแกรมคำนวณจากค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานของข้อมูล ปรับความไวได้ในแถบด้านซ้าย |

## 7. เคล็ดลับและข้อควรระวัง

- **ตรวจเรทราคาทุกครั้ง** ค่าในโปรแกรมเป็นค่าตัวอย่างเริ่มต้น ค่าไฟฟ้าที่แสดงเป็น **ค่าประเมิน** ไม่ใช่ยอดที่ต้องจ่ายจริง
- **ความไวการตรวจจับ (Anomaly)** ถ้าตั้งค่าต่ำ ระบบจะรายงานจุดผิดปกติมากขึ้น ถ้าตั้งค่าสูง จะรายงานเฉพาะจุดที่ผิดปกติมากจริง ๆ
- **ตัวเลขที่ไม่สมเหตุสมผล** ถ้าค่า kW สูงผิดปกติ ระบบจะตัดค่าที่เกิน 2,000,000 ออกเป็น Outlier
- **ข้อมูลเวลาที่อ่านไม่ได้** แถวที่ไม่มีเวลาที่ถูกต้องจะถูกข้ามไป
- **ลองกับไฟล์ตัวอย่างก่อน** ดาวน์โหลดไฟล์แม่แบบจากหน้าแรกเพื่อดูรูปแบบข้อมูลที่โปรแกรมต้องการ
