# คู่มือรูปแบบข้อมูลนำเข้า (Thai Input-Format Guide)

คู่มือนี้อธิบายรูปแบบข้อมูลนำเข้าที่รองรับโดยระบบ (อ้างอิงจาก `data_handler.py` และ `generate_mock_data.py`)

## 1. รูปแบบไฟล์ที่รองรับ
- ไฟล์ที่รองรับ: `.csv`, `.txt`, `.xls`, `.xlsx`

## 2. โครงสร้างคอลัมน์และหัวตาราง
หัวตารางต้องอยู่ใน **50 บรรทัดแรก** ของไฟล์ ระบบค้นหาคอลัมน์โดยใช้คำสำคัญต่อไปนี้ (ไม่สนใจพิมพ์เล็ก-พิมพ์ใหญ่):

*   **วัน/เวลา (Date/Clock):** รองรับคอลัมน์แยก (เช่น Date และ Clock) หรือคอลัมน์รวม (เช่น Clock, Time, Datetime, CH1, เวลา, วันที่)
*   **พลังงานนำเข้า (kW_Import):** ค้นหาคอลัมน์ที่มี kW ร่วมกับ Import, Export หรือ Demand, คอลัมน์ที่มี Active Power, คอลัมน์ชื่อ พลังงาน หรือ กำลังไฟฟ้า, คอลัมน์ชื่อ CH4 หรือคอลัมน์ชื่อ kW เฉย ๆ คอลัมน์ที่มี kWh จะไม่ถูกเลือก
    *   *ข้อจำกัด:* หากมีหลายคอลัมน์ที่เข้าข่าย ระบบจะเลือกคอลัมน์เดียวที่มีผลรวมสูงสุดจาก 20 บรรทัดแรก ไม่ได้รวมหลายคอลัมน์เข้าด้วยกัน เพื่อป้องกันกราฟแสดงค่าเป็น 0
*   **แรงดันไฟฟ้า (Voltage):** ค้นหาคอลัมน์ที่มีคำว่า Voltage, Volt, V, แรงดัน หรือ CH3 (ค่าปริยายหากไม่มีคือ 220)

*   *ข้อจำกัดการตั้งชื่อคอลัมน์:* หากมีชื่อคอลัมน์ซ้ำกัน ระบบจะเปลี่ยนชื่อคอลัมน์ที่ซ้ำโดยเติม `_` ตามด้วยหมายเลขตำแหน่งของคอลัมน์ (เช่น `kw_5`)

## 3. ตัวคั่น (Delimiters สำหรับไฟล์ TXT/CSV)
ระบบตรวจสอบและรองรับตัวคั่น (Delimiters) ดังนี้:
- จุลภาค `,` (Comma)
- แท็บ (Tab)
- อัฒภาค `;` (Semicolon)
- ช่องว่าง (Space)

## 4. การจัดการวันที่และเวลา (Date/Time Parsing)
- รองรับรูปแบบวันเวลาที่ขึ้นต้นด้วยวัน เช่น `dd/mm/yyyy HH:MM` (จาก `pd.to_datetime(dayfirst=True)`)
- หากพบค่าที่ไม่ถูกต้อง (เช่น 'total', 'p', 'op', 'h', 'kwh', 'nan', 'dnv/err') ในคอลัมน์เวลา ข้อมูลบรรทัดนั้นจะถูกข้าม

## 5. การจัดการหน่วยตัวเลข (Numeric Units)
- ระบบจะกรองข้อความและสัญลักษณ์อื่น ๆ ออก เหลือไว้เพียงตัวเลขและจุดทศนิยมโดยใช้ Regular Expression ที่ลบทุกอย่างยกเว้นตัวเลข จุดทศนิยม และเครื่องหมายลบ
- ค่า kW_Import หรือ Voltage ตั้งแต่ 2,000,000 ขึ้นไป **จะไม่ถูกลบ** ระบบจะแสดงคำเตือนพร้อมจำนวนแถวที่พบ ให้ผู้ใช้ตรวจสอบข้อมูลเอง (`preprocess_data` ใน `data_handler.py`)

## 6. ตัวอย่างข้อมูล (Sample Input)
ตัวอย่างรูปแบบไฟล์ที่ `generate_mock_data.py` สร้างขึ้น (หัวตาราง และ 1 แถวแรก):

```csv
Clock,kW_Import,Voltage
2026-01-01T10:00:00,10,220
```

## การตรวจสอบแหล่งที่มาและการทดสอบ
- **แหล่งที่มา:** กฎข้างต้นตรวจจากการอ่านโค้ดใน `data_handler.py` และ `generate_mock_data.py` ในเวอร์ชันปัจจุบัน
- **ยังไม่ได้ทดสอบ:** เอกสารนี้ยังไม่ได้ยืนยันการทำงานของระบบด้วยไฟล์จริงของผู้ใช้
